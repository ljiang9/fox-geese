# fox-geese 狐狸与鹅

1 只狐狸 vs 13 只鹅的不对称围堵棋。纯 Python 标准库，无第三方依赖。

## 玩法

- **棋盘**：十字形 33 点，邻接为上下左右。
- **鹅（你执）**：每回合沿邻接走一步，不能吃子。目标是把狐狸围到无路可走。
- **狐狸（AI）**：每回合可走一步，或跳过相邻的鹅落到空点并吃掉它。
- **胜负**：鹅数 < 6 → 狐狸胜（已无法围堵）；狐狸无合法走法 → 鹅胜；
  同一局面出现三次 → 判和（标准规则）。

## 用法

```bash
python3 -m fox_geese              # 人机对战（你执鹅）
python3 -m fox_geese --auto --games 10 --seed 42   # AI 对 AI 演示
```

人机对战中走法输入如 `3,0-3,1`（起点行,列-终点行,列）。

## AI 说明

- 狐狸：有跳吃必吃；否则走到相邻鹅最多的位置施压，次选靠近最近的鹅。
- 鹅：1 步前瞻评估——重罚送吃的走法，其次最小化狐狸走法数（围堵），
  再收紧鹅群到狐狸的平均距离；近期走过的局面加禁忌分，防原地打转。

## 真实验证记录

- `py_compile` 通过。
- 单元测试全过：狐狸跳吃（吃 1 只、落点正确）、鹅四面围死判胜、
  占位跳吃/幽灵跳吃/错误起点均抛 `ValueError`、鹅 < 6 判狐胜、
  33 点棋盘与初始布子合法、AI 走法合法且 seed 可复现。
- `--auto --games 10 --seed 42`：狐狸胜 7，鹅胜 3，平局 0，
  对局 63–324 手自然结束（seed 7 同样 7:3）。

## 诚实局限

- 双方 AI 都是贪心+1 步前瞻，不会长远规划；熟悉棋理的人类执鹅通常能赢。
- 鹅只能走不能吃，且允许后退（部分传统规则禁止鹅后退）。
- 命令行文本界面，无图形/存档/悔棋；Python 3.10+。
